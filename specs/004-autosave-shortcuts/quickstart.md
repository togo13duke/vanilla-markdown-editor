# Quickstart: 自動保存・デバウンス・ショートカット

**Feature**: 004-autosave-shortcuts
**Date**: 2025-12-28

## 前提条件

- Sprint 3（ファイル管理）が完了していること
- `npm run dev` でアプリケーションが起動すること
- ブラウザ: Chrome, Firefox, Safari, Edge のいずれか

## 機能確認手順

### 1. 自動保存の確認

#### 1.1 基本動作

1. `npm run dev` でアプリケーションを起動
2. ブラウザで http://localhost:5173 を開く
3. ファイルを新規作成（または既存ファイルを選択）
4. エディタに文章を入力
5. **入力を止めて約1秒待つ**
6. 画面右下に「保存しました」のトースト通知が表示されることを確認

#### 1.2 データ復元

1. エディタに「テスト文章です」と入力
2. トースト通知が表示されるまで待つ
3. **ブラウザをリロード（Cmd/Ctrl+R）**
4. 「テスト文章です」が復元されていることを確認

#### 1.3 エラー時の動作

1. DevTools > Application > IndexedDB を開く
2. MarkdownDB を削除
3. エディタに文章を入力
4. 「保存に失敗しました」のエラー通知が表示されることを確認

### 2. デバウンスの確認

#### 2.1 プレビュー更新

1. エディタに `# 見出し` と入力
2. 入力中はプレビューが即座に更新されないことを確認
3. 入力を止めると約150ms後にプレビューが更新されることを確認

#### 2.2 自動保存タイミング

1. 連続して高速に入力を続ける
2. 入力中はトースト通知が表示されないことを確認
3. 入力を止めると約1秒後にトースト通知が表示されることを確認

#### 2.3 パフォーマンス確認

1. 5,000文字以上の長い文章をペーストする
2. 追加で文字を入力する
3. 入力遅延やUIのフリーズが発生しないことを確認

### 3. ショートカットの確認

#### 3.1 手動保存（Cmd/Ctrl+S）

1. エディタに文章を入力
2. トースト通知が表示される前に **Cmd+S**（Mac）または **Ctrl+S**（Windows/Linux）を押す
3. 「保存完了」のトースト通知が即座に表示されることを確認
4. ブラウザの「名前を付けて保存」ダイアログが開かないことを確認

#### 3.2 太字（Cmd/Ctrl+B）- テキスト選択あり

1. エディタに「これは太字です」と入力
2. 「太字」の部分をマウスまたはShift+矢印キーで選択
3. **Cmd+B**（Mac）または **Ctrl+B**（Windows/Linux）を押す
4. 「これは**太字**です」に変換されることを確認
5. プレビューで「太字」が太字で表示されることを確認

#### 3.3 太字（Cmd/Ctrl+B）- テキスト選択なし

1. エディタ内のカーソルを任意の位置に置く（テキスト選択なし）
2. **Cmd+B** または **Ctrl+B** を押す
3. `****` が挿入され、カーソルが `**|**` の位置にあることを確認
4. 「テスト」と入力
5. `**テスト**` となることを確認

#### 3.4 太字トグル（解除）

1. `**太字**` と入力済みの状態で
2. `太字` 部分（`**` を含む）を選択
3. **Cmd+B** または **Ctrl+B** を押す
4. `**` が除去され「太字」のみになることを確認

### 4. トースト通知の確認

#### 4.1 表示位置

1. 保存を実行（自動または手動）
2. 画面右下にトースト通知が表示されることを確認

#### 4.2 自動消去

1. 成功通知が表示された後
2. **3秒後**に自動的に消えることを確認

#### 4.3 エラー通知

1. エラー状態を発生させる（IndexedDB削除など）
2. エラー通知が表示されることを確認
3. エラー通知は**5秒後**に消えることを確認

#### 4.4 通知の上書き

1. 短時間に複数回保存を実行
2. 新しい通知が古い通知を上書きすることを確認
3. 通知が重なって表示されないことを確認

### 5. ファイル切替時の動作

#### 5.1 未保存内容の保存

1. ファイルAを選択して編集
2. トースト通知が表示される前に別のファイルBをクリック
3. ファイルBに切り替わることを確認
4. ファイルAに戻る
5. 編集内容が保存されていることを確認

### 6. エッジケース

#### 6.1 長文での動作

1. 20,000文字以上の文章をペースト
2. 追加で入力
3. 自動保存とプレビュー更新が正常に動作することを確認

#### 6.2 高速入力

1. 毎秒10キーストローク以上で入力
2. 入力遅延が発生しないことを確認
3. 入力停止後に保存が実行されることを確認

## トラブルシューティング

### トースト通知が表示されない

- DevTools Console でエラーを確認
- `style.css` にトースト用スタイルが追加されているか確認

### ショートカットが動作しない

- ブラウザ拡張機能がショートカットをフックしていないか確認
- DevTools Console で keydown イベントが発火しているか確認

### 自動保存が動作しない

- IndexedDB が利用可能か確認（DevTools > Application > IndexedDB）
- `fileService.isDirty` が true になっているか確認
